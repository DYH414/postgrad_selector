# 考研术语与常识

## 学硕 vs 专硕

| | 学术学位硕士（学硕） | 专业学位硕士（专硕） |
|---|---|---|
| 培养目标 | 学术研究、高校教师 | 应用型、职业导向 |
| 学制 | 一般 3 年 | 一般 2-3 年 |
| 学费 | 通常 7000-8000 元/年 | 通常 10000+ 元/年 |
| 考试科目 | 英语一、数学一（多数） | 英语二、数学二（多数） |
| 读博 | 可申请硕博连读 | 一般需要考博 |
| 调剂 | 学硕可调专硕 | 专硕不可调学硕 |

## 全日制 vs 非全日制

- **全日制**：脱产学习，提供住宿，有奖学金。毕业证书注明"全日制"。
- **非全日制**：在职学习（周末或集中授课），一般不提供住宿和奖学金。毕业证书注明"非全日制"。全日制和非全日制考试科目相同，统一划线。

## 推免生

推免生（推荐免试研究生）是指获得本科院校推荐资格、无需参加统考直接录取的考生。985/211 院校推免比例通常较高（30%-50%），双非院校较低（<10%）。

## 统考 vs 自命题

- **统考科目**：全国统一命题，如政治(101)、英语一(201)、英语二(204)、数学一(301)、数学二(302)、408 计算机学科专业基础
- **自命题科目**：各校自行命题，代码通常为 8XX 或 9XX（如 861 自动控制原理）

## 报录比

报录比 = 报考人数 / 录取人数。例如某专业 500 人报考录取 50 人，报录比为 10:1。

**2026 全国数据**：报名 343 万人，计划录取约 87 万（含推免），整体报录比约 4:1。计算机专业热门院校报录比可达 10:1 至 20:1。

## 一志愿 vs 调剂

- **一志愿**：考生在报名时直接填报的志愿学校和专业
- **调剂**：一志愿未被录取后，转到其他有缺额的学校/专业

学校一般优先录取一志愿考生，调剂考生在一志愿录取后进行。

## 复试线 vs 录取线

- **复试线**：进入复试的最低分数要求（不等于录取）
- **录取线**：实际被录取考生的最低分数（通常 ≥ 复试线）

复试差额比 120% 意味着复试 120 人最终录取 100 人。

## 国家线 / 自划线 / 院线

- **国家线**：教育部划定的基本分数线（A 区 / B 区）
- **自划线**：34 所 985 院校自行划定、通常高于国家线
- **院线**：学院/专业在国家线基础上额外划定的复试线

## 考试科目编码规则

N诺和考研网站常用缩写表示考试科目组合：

- **11408** = 101 政治 + 201 英语一 + 301 数学一 + 408 计算机综合
- **22408** = 101 政治 + 204 英语二 + 302 数学二 + 408 计算机综合
