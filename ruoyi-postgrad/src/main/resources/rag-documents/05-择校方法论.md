# 择校方法论

## 筛选维度

择校建议从以下维度综合考虑：

### 1. 考试科目（第一优先级）

**是否考 408** 是择校最重要的决策点。408 统考的优势：
- 全国统一命题，公平性高
- 调剂面广：408 考生可以调剂到任何考 408 的学校
- 备考资源丰富，历年真题透明

自命题的风险：
- 一志愿不录则调剂面极窄，大部分学校只收 408 考生

### 2. 学校层次与城市

- **985**：学术资源丰富，推免比例高（40%-60%），统考名额少
- **211/双一流**：计算机强校集中在这一层，性价比最高
- **双非强校**：杭电、深大、重邮等 CS 实力不输 211

城市影响实习和就业。计算机就业集中城市：北京、上海、深圳、杭州、成都、南京。

### 3. 录取数据（核心指标）

- **复试线**：最低门槛，但实际录取分通常远高于此
- **录取均分**：比复试线更有参考价值
- **报录比**：10:1 以上为热门，5:1 以下为冷门
- **招生人数**：<10 人风险大，波动性高

### 4. 学硕 vs 专硕

- 学硕：名额少，可硕博连读，学费低（7000-8000/年）
- 专硕：名额多，报考人数更多，分数可能更高，学费高（10000+/年）

## 408 考生择校策略

1. 确定目标分数区间，分冲/稳/保三档
2. 408 覆盖 150+ 所学校，选择面足够宽
3. 调剂时有绝对优势
4. 不要只看复试线——复试线 273 录取均分可能 350+
5. 避开连续缩招的学校

## 常见误区

- ❌ "复试线低的学校好考" → 实际录取分可能远超复试线
- ❌ "双非一定比211好考" → 深大计算机堪比211难度
- ❌ "408太难不如考自命题" → 自命题一志愿不录基本无调剂机会

> 来源: 各校招生录取数据、N诺考研数据、研招网
