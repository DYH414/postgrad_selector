## 跨文件统一项

### 15. 备选/收藏命名统一

全部统一为 **"备选"** 和 **"加入备选/移出备选"**：

| 文件 | 当前 | 改为 |
|------|------|------|
| `Favorites.vue` 页面标题 | `我的收藏` | `我的备选` |
| `Favorites.vue` 空状态 | `暂无收藏` | `暂无备选` |
| `Favorites.vue` API 目录名 | `favorites` | 保持不变（只改用户可见文案，不改代码标识符） |
| `Favorites.vue` 操作按钮 | `取消收藏` | `移出备选` |

### 16. 数据免责声明统一

在各页面底部使用统一的简短声明，不再逐页重复写散装文案。新建或复用已有 `<DataDisclaimer />` 组件：

```
数据来源为历年招生录取公开信息整理。数据可能存在遗漏，各院校最新政策以学校官网公告为准。
```
